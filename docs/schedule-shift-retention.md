# 予定管理移行：スタッフシフト保持

- スタッフシフトも予定管理の移行対象とする。

- シフト画面や操作仕様の変更は別工程とし、今回の移行では行わない。
- 実データ移行と照合が完了するまで元シートを削除しない。
